## 📌 Problem & Solution

Traditional student organizations and college clubs struggle with two persistent problems:
1. **Ghost Membership:** Enthusiastic first-year students join clubs but disengage due to intimidating tasks or unclear expectations.
2. **Lead Burnout:** A handful of club leads end up executing 90% of the workload because delegating is harder than doing it themselves.

**SyncSphere** bridges this gap by introducing:
* **10–30 Minute Micro-Tasks:** Bite-sized, self-contained contribution tickets with clear acceptance criteria and asset links.
* **30-Day Buddy Onboarding:** 1-on-1 peer matching between senior mentors and new joiners to guide their first month.
* **Lead Cockpit & Workload Heatmap:** High-level dashboard tracking distribution of work to spot bottlenecks before burnout occurs.
* **Verified Contribution Credits & Badges:** Tamper-proof badges and verifiable proof of work for student resumes and portfolios.
* **Club Resource Vault:** Centralized SOPs, playbooks, design assets, and event toolkits.

## 🏃 Running Locally

Since SyncSphere is built with pure web standards, no compilation or npm dependencies are required:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Shubh-153/syncsphere.git
   cd syncsphere
   ```

2. **Serve locally:**
   You can open `index.html` directly in your browser, or use any local HTTP server:
   ```bash
   # Using Python 3
   python3 -m http.server 8000
   
   # Or using npx serve
   npx serve .
   ```

3. **Visit in browser:**
   Open [http://localhost:8000](http://localhost:8000).
